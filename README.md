# 帰巣本能

子アヒルになって、お母さんについて巣まで帰るブラウザミニゲームです。公園で岩をよけ、人でいっぱいの歩道をはじっこ伝いに歩き、高速道路を車線のあいだで待ちながら渡り、人混みをぬけます。はぐれた子に近づくと助けられます。

## 開発

```bash
npm install
npm run dev
npm run build
npm run probe
```

`npm run dev` でローカルサーバーが開きます。`npm run build` は `dist/` に静的ファイルを出します。`npm run probe` は操作なしで巣まで帰れるかをシミュレーションします。

## 計測

[GoatCounter](https://www.goatcounter.com/) で匿名のプレイ回数を数えています（`src/metrics.ts`）。Cookie は使わず、送るのはイベント名とリファラーだけです。開発サーバーと、隠しステージセレクトを使ったあとは送信しません。

| イベント | 意味 |
|------|------|
| `open` | ページを開いた |
| `start` | はじめた |
| `reach/<ステージ>` | そのステージに到達した |
| `fail/<場所>` | そこで残機を失った |
| `gameover/<場所>` | そこで残機が尽きた |
| `retry` | やり直した |
| `clear` | クリアした |
| `share` | シェアボタンを押した |
